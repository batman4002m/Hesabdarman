# حسابدار من — نسخه ۱۳
PWA فارسی و موبایل‌محور برای مدیریت درآمد و هزینه؛ کاملاً آفلاین و بدون سرور.

## امکانات
- ثبت درآمد و هزینه (با اقلام خرید و جمع خودکار)، ویرایش و حذف
- تاریخ جلالی با اعتبارسنجی (سال کبیسه هم لحاظ می‌شود)
- گزارش ماهانه، نمودار «پول کجا رفت؟»
- جستجو (اعداد فارسی/انگلیسی، ی/ک عربی و فارسی)
- بکاپ JSON، بازیابی امن (اعتبارسنجی و تأیید)، خروجی CSV
- یادآوری بکاپ بعد از ۷ روز، آموزش تعاملی، تم تیره/روشن و رنگ دلخواه
- نصب روی گوشی و کار آفلاین (Service Worker + آیکون PNG)

## اجرا روی GitHub Pages
تمام فایل‌ها را در ریشه repository قرار بده و Pages را روی همان شاخه فعال کن. برنامه باید از https باز شود.
